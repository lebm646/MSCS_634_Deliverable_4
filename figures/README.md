# Figure guide

PNG files are exported by the consolidated notebook and are also embedded in its saved outputs.

1. `01_eda_overview.png` — Numeric distributions, duration/amount relationship, correlations, and label imbalance.
2. `02_eda_purpose_and_log.png` — Credit amounts by purpose and log-transformed amount distribution.
3. `03_regression_evaluation.png` — CV/test RMSE, selected-model predictions, and residuals.
4. `04_regression_importance.png` — Descriptive permutation importance with repeat variability.
5. `05_classification_performance.png` — ROC curves and minority-class precision/recall/F1.
6. `06_confusion_matrices.png` — Actual/predicted class counts for all six classifiers, including baseline.
7. `07_clustering_diagnostics.png` — Inertia, silhouette, and PCA display of three clusters.
8. `08_cluster_profiles.png` — Standardized cluster means and post-clustering bad-label fractions.
9. `09_hierarchical_dendrogram.png` — Full-sample Ward hierarchy, truncated for readability.
10. `10_association_rules.png` — All-rule support/confidence and highest-lift bad-label rules.
11. `11_subgroup_error_audit.png` — Selected classifier's error rates by recorded sex and age group.

These plots describe this historical sample. Correlations, cluster membership, and rule confidence are not causal or independently validated lending evidence.
